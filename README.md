## 开服要多少内存和 CPU：按人数和模组算

tModLoader 服务端的内存开销主要来自模组数量和世界大小，人数反而是次要变量。灾厄这种大型整合，光是加载模组本体就会吃掉一两个 G。

给一条可以直接照抄的规则：

- **原版或几个小模组，2–4 人**：2G 内存够。
- **带灾厄或同量级中型整合**：2 核 4G 起。开源面板项目 tml-panel 的作者给的也是这个口径，"内存建议 2G 起；只要装了灾厄这种大模组，4G 更稳"。
- **8 人以上，或整合包里塞了三四十个模组**：4 核 8G 以上。雨云页面给的分档是 4 核 8G+，它卖服务器，有抬配动机，但这个数字和灾厄整合的实际体量对得上。

**CPU 主频比核心数更重要。** 泰拉瑞亚服务端基本是单线程跑世界逻辑，多给核心用不上，单核频率低就直接体现为卡顿和延迟。这也解释了为什么 Ryzen 档比 E5 档贵一截：5900X 标称 4.8GHz、7950X 5.7GHz、i9-14900KF 6.3GHz，E5-2666 v3 是早年的服务器 U，主频低但便宜，跑原版轻度联机没问题，跑灾厄会明显吃力。

玩家上限方面有个容易混的地方：tModLoader 官方 `serverconfig.txt` 里 `maxplayers` 的取值允许 1 到 255；而雨云页面引用的是"泰拉瑞亚官方说明，1.4.0.1 版本后服务器默认支持最大 16 名玩家同时在线"。前者是配置允许的范围，后者是默认上限，两回事，实际开服按人数设就行，不必纠结这个数字。

## 三条开服路线，各自的门槛在哪

### 路线一：本机 `start-tModLoaderServer.bat`

零成本，游戏目录里就有这个批处理文件，双击跑起来就是一个服务端。灾厄整合包的作者也建议用这种方式联机，"联机体验更佳"。

代价是明显的：你的电脑必须一直开着，夏天风扇噪音和电费是实打实的；家用宽带的上行带宽有限，人一多就卡；没有固定公网 IP，每次重开都要重新告诉朋友地址。断网或者你合盖睡眠，所有人当场掉线，世界进度停在那一刻。适合"今晚打两小时"这种玩法，不适合长期存档。

### 路线二：自己买 VPS 装面板

有 Linux 基础的人会想走这条。开源项目 `tml-panel`（MIT 协议）是目前比较完整的一个方案，裸机加 systemd，不依赖 Docker，一个网页面板管一台 tModLoader 专用服。它能做的事不少：一键装服务端、工坊搜模组自动递归补前置依赖、本体一键升级带失败回滚、世界备份、网页里发 `save`/`say`/`kick` 命令。

但真实的门槛得说清楚，项目文档里全写着：

面板默认只监听 `127.0.0.1:8765`，这是刻意的安全设计。你要在自己电脑上执行 `ssh -L 8765:127.0.0.1:8765 root@服务器IP` 做端口转发，才能打开面板。首次进入要输入一次性 setup token 设管理员密码。面板以 root 身份运行，项目原话是"面板密码等同 root"，密码强度自己负责。

装完之后还要去云厂商控制台的安全组里放行 **7777/TCP**，否则服务端在跑、玩家也连不上。大陆机器直连 GitHub 下载 tModLoader 基本是龟速甚至断流，部署脚本得加 `--cn` 走国内镜像，或者自建 `TML_GH_PROXY`。首次启动要下 .NET 运行时再建世界，弱网环境下超过 10 分钟、健康检查超时都算正常现象，得去日志页确认它还在推进。

这些都不是坑，是自建方案本身的工作量。愿意花一晚上折腾，换来的是完全的控制权；不想碰 SSH 和端口转发，就走第三条。

### 路线三：买面板服

购买时在配置页选 Terraria + tShock，进控制台下拉到 MCSManager 面板按提示启动，看到 `Server started` 就把 IP 和端口发给朋友。整个过程不需要 SSH，不需要敲 Linux 命令，页面给的时间是 10–15 分钟。

要装 tModLoader 的话，流程不是"选个 tModLoader 就完事"，而是按平台已有的教程替换服务端文件、再改启动脚本，同样在面板里完成。这一点最好在下单前心里有数，别指望和 tShock 一样一键到位。

其他几项：内置 BGP 高防，普通私服被 DDoS 的情况不多，有被攻击经历可以选防御更高的机房；动态计费在没人在线时 CPU 占用低，自动少扣费。机房方面大陆推荐宿迁、十堰、广州，跨境和香港走 BGP 优化线路。

## serverconfig.txt 怎么填：几个容易踩的设置

服务端默认读取同目录下的 `serverconfig.txt`，想用别的文件名就加 `-config 文件名.txt`。这里有一行注释值得单独拎出来：**除非指定了世界，maxplayers、端口、端口转发这些设置都会被忽略**。很多人改完端口发现没生效，就是因为配置里没有 `world=` 这一行，服务端根本没进入加载世界的流程。

常用项：

- `port=7777`，默认端口，改完记得同步安全组
- `maxplayers=8`，取值 1–255
- `language=zh-Hans`，简中；繁中用 `zh-Hant`
- `npcstream=60`，降低敌怪跳帧但增加带宽，0 为关闭。人多带宽紧可以调高，追求手感可以调低
- `secure=1`，增加防作弊
- `upnp=1`，自动端口转发。云服务器上一般用不上，安全组自己放行更可控

难度参数按官方配置文件注释只有两个值：`0` 普通、`1` 专家。网上流传的"0 经典 / 1 专家 / 2 大师 / 3 旅程"是另一套说法，和官方文件对不上，大师和旅程难度在游戏内建世界时选更稳妥。

**tModLoader 专属的三个参数**，原版泰拉瑞亚没有：

- `-tmlsavedirectory`：指定 tML 存档目录，Mod 和 World 目录都由它派生。想把存档放到数据盘就靠这个
- `-modpack`：指定加载哪个模组包，只有包里的模组会被加载
- `-modpath`：手动安装的模组从哪个目录读取

## 模组和版本对齐：先定整合包，再定配置

顺序搞反是新手最常见的浪费。先去创意工坊把整合包定下来，看清楚它要求什么版本，再回来决定买多大内存。

以流传较广的灾厄整合为例，标注版本是灾厄 v2.0.0.3。必备的只有两个：Calamity mod 本体和 Calamity mod music 音乐包（不装也能玩，但作者强烈推荐）。剩下十几二十个是辅助类，AlchemistNPC Lite 加售卖 NPC、Magic Storage 做储物、Recipe Browser 查合成表、Quality of Life 改药水和弹药消耗、Better Multiplayer 自动入队并禁 BOSS 战复活，按需订阅。

这份整合里明确没收 Boss Checklist，理由是"据说此模组目前存在恶性BUG会影响游戏进程"。整合包里带 `[1.4 Alpha]` 前缀的模组也不少，说明内部版本参差，别指望所有模组都能在 1.4 上跑。tModLoader 官方也讲过，1.3 到 1.4 的改动让大量旧模组不适配，"有的模组永远也不会更新到 1.4"。

服务端和客户端的模组列表必须一致，这是硬要求。整合包更新了，服务端也得跟着换，否则玩家进不来或者进来就崩。tml-panel 的"本体一键升级带失败回滚"解决的正是这个问题；面板服则要手动替换服务端文件。

进游戏前还有两步别忘：主界面进创意工坊的模组管理，把订阅的模组全部启用；进游戏后在设置里的模组控件把常用功能绑定一遍，或者拉到底端点全部重置为默认。

## 常见问题

**2G 内存够不够？**
原版或少量模组、4 人以内，够。带灾厄就是 4G 更稳，别在内存上省那点钱，模组加载失败排查起来很费时间。

**面板服能装灾厄吗？**
能。按平台的 tModLoader 教程替换服务端文件、改启动脚本，再在面板的模组管理里装齐整合包。4G 起步，8 人以上建议 4 核 8G。

**原版朋友能进吗？**
不能。所有人必须装 tModLoader，且版本与服务端一致。这是 TML 的设计前提，没有绕过的办法。

**端口 7777 打不开怎么办？**
八成是安全组没放行。云厂商控制台的防火墙默认只开 22 和少量端口，要去手动加一条 7777/TCP 的入站规则。本机开服则要检查 Windows 防火墙和路由器端口映射。

**一个月大概多少钱？**
按参考价，2–4 人原版约 ¥15/月起，带灾厄 4–8 人约 ¥40/月起，大型整合约 ¥55/月起。年付 7 折叠加首月 5 折会低不少，但所有价格以购买页为准，选内存和机房时会变。

**买了不合适能退吗？**
